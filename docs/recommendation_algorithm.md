# 个性化推荐算法实现全流程详解

## 1. 算法核心思路
本项目采用 **“四路混合推荐引擎 (Hybrid Recommendation Engine)”**，结合了用户画像、内容属性、群体行为及心理状态四个维度，通过加权融合算法实现动态精准推荐。

## 2. 四路推荐详解

### 第一路：基于心理画像的推荐 (Profile-Based)
*   **输入**: 心理测评结果（SDS, SCL-90, UPI）。
*   **逻辑**: 后端将测评等级映射为 `stress_level`, `anxiety_level`, `depression_level`。
*   **实现**: SQL 匹配引擎根据用户当前的风险等级（如“中度抑郁”），在资源库中高权重召回相关干预资源。

### 第二路：基于内容的推荐 (Content-Based)
*   **输入**: 资源的标签 (Tags) 与 用户的兴趣标签 (Interest Tags)。
*   **逻辑**: 提取用户近期浏览、点赞的资源关键词，并结合情绪日记中的标签。
*   **权重**: 兴趣得分随着用户的持续互动动态衰减。

### 第三路：基于用户的协同过滤 (User-CF)
*   **输入**: 用户资源互动矩阵。
*   **逻辑**: 计算用户间的余弦相似度。如果“用户A”和“用户B”都喜欢资源X，则将“用户B”喜欢的资源Y推荐给“用户A”。
*   **优化**: 引入时间衰减因子，近期行为的权重高于远期行为。

### 第四路：基于物品的协同过滤 (Item-CF)
*   **逻辑**: 计算资源间的相似度。如果您观看了《抑郁缓解视频》，系统会根据群体行为数据，推送与之强关联的《正念冥想练习》。

## 3. 全流程执行步骤

### 步骤 A：实时行为捕捉 (Feedback Loop)
*   **测评提交**: 触发 `updateRecommendationProfile`，即时注入核心画像。
*   **写日记**: 提取情绪词，作为短期兴趣漂移输入。
*   **点赞/收藏**: 产生强偏好信号，得分贡献度最高。
*   **阅读/观看**: 记录点击行为，产生弱偏好信号。

### 步骤 B：多路并发召回 (Retrieval)
*   推荐引擎同时启动四路算法，每路获取 Top-N 条候选资源。

### 步骤 C：归一化与加权融合 (Ranking)
*   **Min-Max归一化**: 将不同算法的原始分数统一映射到 `[0, 1]`。
*   **加权求和**: 
    `Final_Score = (Profile_Score * 0.3) + (Content_Score * 0.3) + (User_CF * 0.2) + (Item_CF * 0.2)`
*   **排序**: 按 `Final_Score` 进行倒序排列。

### 步骤 D：多样性过滤 (Rerank)
*   **去重**: 过滤掉用户已看过的资源。
*   **打散**: 限制同类型资源（如纯视频）的展示上限（40%），防止信息茧房。
*   **兜底**: 推荐数量不足时，自动填充全站热门资源。

## 4. 推荐逻辑示例
1.  **用户测评**: 显示“轻度抑郁”。
2.  **引擎响应**: 心理画像路得分飙升，将《抑郁情绪的识别与应对》排在首位。
3.  **用户行为**: 用户虽然有抑郁倾向，但刚才点赞了两篇“人际关系”文章。
4.  **动态调整**: 内容路分值上升，下一次刷新时，排名变为：1.《抑郁缓解》 2.《沟通技巧》。
