# 大学生心理健康平台 - 功能实现文档

## 1. 总体架构
本项目采用前后端分离架构：
*   **前端**: UniApp (Vue2) + SCSS，支持多端发布。
*   **后端**: Spring Boot + MyBatis Plus + MySQL。
*   **核心引擎**: 基于多路混合算法的个性化推荐系统。

## 2. 核心模块实现详情

### 2.1 心理测评模块
*   **多量表支持**: 系统内置 SDS (抑郁自评)、SCL-90 (症状自评)、UPI (大学生人格问卷) 等多种标准量表。
*   **答题交互**: 采用平滑的自动跳题逻辑（800ms延时），支持防抖处理，确保用户体验。
*   **专业评分**: 后端根据量表标准算法计算原始分与标准分，并生成雷达图所需的维度数据。
*   **画像联动**: 测评结果会自动更新 `user_psychological_profile` 表，作为推荐系统的核心输入。

### 2.2 情绪日记模块
*   **记录与更新**: 采用“智能更新(Upsert)”逻辑，确保用户每日记录的唯一性。
*   **心境感应**: 提取日记中的情绪标签（如：焦虑、孤独、开心），实时反馈至推荐引擎。
*   **趋势分析**: 提供情绪波动曲线及统计图表，帮助用户直观了解心理动态。

### 2.3 教育资源模块
*   **多媒体支持**: 集成视频播放、音频收听及图文阅读功能。
*   **学习追踪**: 实时记录学习时长与进度，点击“已完成”或观看结束自动更新状态。
*   **互动反馈**: 支持对资源进行点赞、收藏及二级评论，所有交互行为均作为推荐系统的权重输入。

### 2.4 匿名社区模块
*   **分类展示**: 支持按不同心理话题进行分类讨论。
*   **隐私保护**: 严格保护用户隐私，采用昵称系统进行交流。

---

## 3. 技术亮点
*   **响应式数据流**: 针对 Vue 2 的响应式限制，采用对象解构与 `$set` 结合，确保 UI 状态实时同步。
*   **健壮性设计**: 后端采用 Jackson 强制 JSON 序列化，并建立全局异常拦截机制。
*   **资源映射**: 建立灵活的静态资源映射机制，支持本地文件系统作为媒体服务器。
